Streaming Paradigm

Async Token Pumping and Typewriter UI Realization

Physical Atlas / Async Marshalling Flow
01 / Technical Depth

Local AI computation is performed token-by-token. To eliminate the feeling of waiting, the plugin leverages an Async Pumping mechanism to deliver character fragments in real-time.

  • Thread Marshalling: While the kernel handles inference in the background, OnChunk delegates are guaranteed to trigger on the GameThread. No manual multi-threading UI sync required.
  • Streaming Consistency: Each chunk delivers only the net delta. The application simply appends the text to achieve 0-stutter typewriter interactions.
02 / Source Code Demo

Streaming UI implementation from WinyunqDialogueWidget.cpp:

// 1. Define Lambda for chunk listening
FLiteRtLmChunkCallback OnChunk = FLiteRtLmChunkCallback::CreateLambda(
    [this](const FString& Chunk) {
        // Automatically marshalled to GameThread; direct UMG access safe
        CurrentDisplayBuffer += Chunk;
        Text_Dialogue->SetText(FText::FromString(CurrentDisplayBuffer));
        
        // Trigger scrolling or sound effects
        ScrollToBottom();
    }
);

// 2. Submit Inference Request
FLiteRtLmUnrealApi::SendChatRequest(..., OnChunk, ...);
