Structural Constraints

Constrained Decoding and Business Action Triggering

Physical Atlas / Command Generation & Conversion
01 / Technical Depth

To prevent AI from outputting conversational "fluff" when expecting commands, the plugin supports hard constraints at the probability sampling stage. This ensures every character produced adheres to a predefined grammar.

  • JSON Mode: Automatically completes brackets and forces valid JSON key-value pairs. This powers the application's tool-calling logic.
  • Tool Injection: The plugin uses json_preface techniques to declare available Unreal functions to the AI, enabling "Thought-to-Action" capabilities.
02 / Source Code Demo

Configuring constraints and consuming structural results:

// 1. Set Constraint Type
FLiteRtLmSamplingParams Params;
Params.ConstraintType = ELiteRtLmConstraintType::Json;

// 2. Inject Tool Definitions (UmgMcp Standard)
FString ToolsJson = "[{\"name\":\"attack\", \"parameters\":{...}}]";

// 3. Consume structural actions in OnDone
void OnInferenceDone(const FLiteRtLmResult& Result) {
    for (auto Call : Result.ToolCalls) {
        FString FuncName = Call->GetStringField("name");
        ExecuteInternalAction(FuncName, Call->GetObjectField("parameters"));
    }
}
