Incremental Pushing and Role Normalization Protocols

Physical Atlas / Incremental Flow
01 / Technical Depth

In traditional Web APIs, full history must be uploaded for every turn. LiteRT-LM implements an Incremental Sync Protocol leveraging persistent KV Cache.

Role Normalization (Gemma Merge)

Models like Gemma do not support native system roles. The plugin automatically merges system prompts into the first user turn and flattens tool results to maintain compatibility.

Delta Tracking

The plugin tracks LastSentCount per session. If the history grows, only the new tokens are pushed to the kernel, keeping prefill latency low regardless of dialogue length.
