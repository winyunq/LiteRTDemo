01 / Technical Depth

KV Cache is the physical memory of an LLM. Reusing it means no redundant computation of history text, leading to 5x-10x faster response times.

  • Instant Context Switching: The plugin maps Unreal object addresses (void*) directly to VRAM slots. Switching Agent latency is < 1ms.
  • Memory Reclamation: VRAM slots are finite. While the plugin implements LRU eviction, business logic must explicitly signal session release on object destruction.
