Context Window

128K Physical Standard and Sliding Window Strategies

Physical Atlas / Sliding Window Mechanics
01 / Technical Depth

The context window defines the length of an AI NPC's "working memory." In LiteRTDemo, we adopt the 128K (131,072) Tokens physical standard.

  • Persona Anchoring: The kernel automatically protects the System Prompt. Even when sliding window eviction occurs, the core personality weights are preserved.
  • Sliding Physics: When the VRAM slot is full, the kernel physically evicts the oldest non-system messages. With a 128K window, this is rarely triggered in typical gameplay.
02 / Source Code Demo

Defining physical bounds in FUmgMcpLiteRtLmAiProvider:

// 1. Set 128K Ultra-long Context Standard
FLiteRtLmConfig Config = FLiteRtLmUnrealApi::GetAutoConfig();
Config.MaxNumTokens = 128 * 1024;  // Allocates ~1.5GB KV Cache

// 2. Limit single response length
FLiteRtLmSamplingParams Params;
Params.MaxTokens = 4096; // Prevent budget exhaustion by single response

// 3. Application Push
FLiteRtLmUnrealApi::SendChatRequest(..., Params);
