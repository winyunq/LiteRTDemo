Wrapper / C ABI / DLL

LiteRT-LM C API and DLL Architecture

This page is the maintained map for the stable C ABI exposed by `litert_lm_wrapper.dll`. It keeps the call order, data contracts, message synchronization, inference entry points, and cleanup rules easy to find. For Blueprint-only usage, start from the Unreal plugin section in the main manual.

Recommended order Confirm backend and model paths, create the Engine and Conversation, append messages, then run inference. Core entry: LiteRtLm_RunInference

Lifecycle

Minimal Call Chain

1. Query backends LiteRtLm_GetAvailableBackends
2. Create engine LiteRtLm_CreateEngine
3. Create conversation LiteRtLm_CreateConversation
4. Append messages AppendUserMessage
5. Run inference LiteRtLm_RunInference
6. Release handles DestroyConversation

Data Contract

Structs and Callback

LiteRtLm_Config Model path, backend, device, LoRA, vision model, audio model, and other initialization fields. LiteRtLm_SamplingParams Temperature, Top-K, Top-P, seed, max tokens, and other generation controls. LiteRtLm_Result Synchronous result container with status, error text, and releasable output buffers. LiteRtLmCallback Streaming token, error, completion, and user context callback protocol.
