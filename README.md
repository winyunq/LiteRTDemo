# LiteRTDemo

A specialized AI-assisted UMG workflow demo for Unreal Engine 5, featuring **LiteRT (TensorFlow Lite)** and **UMG MCP**.

## Features
- **Local AI Inference**: Powered by [LiteRT-LM-Unreal](https://github.com/winyunq/LiteRT-LM-Unreal).
- **UMG MCP Integration**: Seamless AI-assisted UI design and interaction.
- **Winyunq Strategy**: High-efficiency development workflow.

## Project Structure
- `Source/UmgMcp`: Core logic for the UMG MCP system.
- `Plugins/LiteRT-LM-Unreal`: Local LLM inference backend (Submodule).
- `Content/`: Demo assets and UMG layouts.

## Getting Started
1. Clone the repository:
   ```bash
   git clone --recursive https://github.com/winyunq/LiteRTDemo.git
   ```
2. Open `LiteRTDemo.uproject` with Unreal Engine 5.4+.
3. Build the solution and run.
